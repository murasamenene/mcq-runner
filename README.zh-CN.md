# mcq-runner

[English](README.md) | 简体中文

一个轻量、无依赖、完全在浏览器中运行的选择题答题器。前端与题库分离：打开应用、选择一个 JSON 题库文件，即可开始答题。无需服务器、构建步骤、账号或网络请求。

界面当前使用简体中文。

## 功能

- 支持单选题和多选题。
- 每个题库可配置两种答案查看模式：
  - `immediate` — 每答完一题立即显示答案和解析。
  - `afterAll` — 全部题目作答完毕后才显示答案。
- 支持上一题/下一题导航，回看时保留已选答案。
- 题库标题旁显示 `HH:MM:SS` 计时器；可选题库时间限制，超时后计时器变红。
- 导航规则明确：`immediate` 模式下已提交的答案不能修改；`afterAll` 模式在请求最终结果前可以修改答案。
- 最终结果分为 **错题与解析** 和 **正确题目解析** 两个部分。
- 提供详细的题库校验和明确的错误提示。
- 极简复古的 tkinter 风格视觉设计，不使用外部素材或字体。

## 快速开始

1. 直接在浏览器中打开 `index.html`。
2. 点击 **选择题库…**。
3. 选择 `example-bank.json` 或你自己的 UTF-8 JSON 题库。
4. 根据题库的答案查看模式作答。
5. 在结果页查看错题和正确题目，重新挑战同一题库，或选择另一个题库。

无需启动本地服务器。应用通过浏览器的 File API 在本地读取所选文件。

## 答题模式

在题库顶层设置 `reviewMode` 字段。

| 值 | 行为 |
| --- | --- |
| `immediate` | 每道题单独提交。提交后立即显示反馈、正确答案和解析，并锁定该题答案。 |
| `afterAll` | 作答期间隐藏答案。使用 **上一题** 和 **下一题** 导航，选择会被保留。每道题至少选择一个答案后，**查看结果** 才可用。 |

如果省略 `reviewMode`，默认使用 `immediate`，以兼容旧题库。

### `immediate`

- 选择一个答案并点击 **提交答案**。
- 立即显示结果和解析。
- **上一题** 可回看之前已提交的题目；**下一题** 继续答题。
- 最后一题提交后，点击 **查看结果**。

### `afterAll`

- 选择答案时立即记录，但不显示对错信息。
- **上一题** 和 **下一题** 用于在题目之间移动。
- 在所有题目都至少选择一个答案之前，**查看结果** 按钮保持禁用。
- 请求结果时统一判分所有题目。

## 计时器与时间限制

题库成功加载后开始计时，并以 `HH:MM:SS` 格式显示在题库标题旁边。重新答题或切换题库时计时器会重置，进入结果页后停止计时。

可选的顶层字段 `timeLimit` 用于设置时限，格式为 `HH:MM:SS`（例如 `"00:30:00"`）。填写后会在计时器旁显示时间限制；当计时超过限制后，计时器变为红色。该字段留空或省略表示不限制时间。

## 题库格式

题库是单个 UTF-8 JSON 文件，题目按数组顺序显示。

```json
{
  "title": "Web 基础",
  "reviewMode": "immediate",
  "timeLimit": "00:30:00",
  "questions": [
    {
      "question": "HTML 文档使用哪种文件扩展名？",
      "options": ["html", "txt", "exe", "css"],
      "answer": "A",
      "explanation": "HTML 文档使用 .html 扩展名。"
    },
    {
      "question": "以下哪些是 Web 浏览器？",
      "options": ["Edge", "Chrome", "Photoshop", "Firefox"],
      "answer": ["A", "B", "D"],
      "explanation": "Edge、Chrome 和 Firefox 是浏览器；Photoshop 是图像编辑器。"
    }
  ]
}
```

### 字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `title` | 否 | 显示在答题页和结果页的题库名称。省略或为空时，使用去掉 `.json` 的文件名。必须是字符串。 |
| `reviewMode` | 否 | `"immediate"` 或 `"afterAll"`，默认为 `"immediate"`。 |
| `timeLimit` | 否 | 可选的答题时限，格式为 `HH:MM:SS`，例如 `"00:30:00"`。留空或省略表示不限制时间；填写后会显示在计时器旁边。 |
| `questions` | 是 | 非空的题目对象数组。 |
| `questions[].question` | 是 | 非空题干。支持换行。 |
| `questions[].options` | 是 | 由 2–26 个非空字符串组成的选项数组。 |
| `questions[].answer` | 是 | 单选题使用单个字母（例如 `"A"`）；多选题使用字母数组（例如 `["A", "C"]`）。大小写不敏感。 |
| `questions[].explanation` | 否 | 在答题反馈和结果页显示的解析。必须是字符串。 |

未知字段会被忽略。

### 答案规则

- 选项按数组顺序标记为 A、B、C 等。
- `answer` 为字符串时生成单选框，并按单选题判分。
- `answer` 为数组时生成复选框，并按多选题判分；即使数组中只有一个字母也是如此。
- 多选题必须与正确答案集合完全一致才得分，没有部分分。
- 最终正确率四舍五入为整数百分比。

## 结果

两种模式结束后都会显示相同的两个结果部分：

- **错题与解析**：题目、你的答案、正确答案和解析。
- **正确题目解析**：题目、正确答案和解析。

如果某个部分没有题目，结果页会显示 **无错题。** 或 **无正确题目。**。如果某题没有解析，页面会显示 **解析：题库未提供解析。**。

## 校验

答题开始前会校验整个文件。无效题库会停留在起始页，并显示具体错误。应用会拒绝以下情况：

- 无效 JSON；
- 根节点不是对象；
- `questions` 数组缺失、不是数组或为空；
- `reviewMode` 不是 `"immediate"` 或 `"afterAll"`；
- `timeLimit` 格式无效（必须使用 `HH:MM:SS` 格式）；
- 题干或选项文本为空；
- 选项数量不在 2–26 之间；
- 答案字母格式错误、越界或重复；
- `title` 或 `explanation` 不是字符串。

请将题库保存为 UTF-8，以避免中文乱码。在 Windows 记事本中保存时，请选择 UTF-8。

## 键盘与导航

- 使用 Tab 键在选项和按钮之间移动。
- 单选按钮支持方向键选择；复选框支持空格键。
- `immediate` 模式下，已提交的题目会被锁定，但仍可回看。
- `afterAll` 模式下，在请求结果前可以修改答案。

## 浏览器支持

支持现代版本的浏览器。应用可以直接从磁盘打开（`file://`），并且仅在用户选择题库文件后读取内容。没有外部依赖、CDN 或网络请求。

答题状态仅保存在内存中。刷新页面会清除当前答题进度。
