# mcq-runner

[English](README.md) | 简体中文

一个纯静态的 HTML 选择题答题器。前端与题库分离：启动 `index.html` 后选择自己的 JSON 题库文件即可开始答题，无需安装依赖、构建或启动服务器。

## 快速开始

1. 双击 `index.html`，用 Edge、Chrome、Firefox 等现代浏览器打开。
2. 点击“选择题库…”，选择 `example-bank.json`（或你自己的题库文件）。
3. 根据题库中设置的答题模式作答。
4. 完成后查看成绩、错题和正确题目解析，可重新答题或更换题库。

页面通过本地文件读取题库，不会上传数据，也不会发起网络请求。刷新页面会清空本次答题进度。

## 题库格式

题库是单个 UTF-8 编码的 JSON 文件，扩展名建议为 `.json`。题目按照 `questions` 数组中的顺序出现。

```json
{
  "title": "示例题库",
  "reviewMode": "immediate",
  "questions": [
    {
      "question": "HTML 文件的扩展名是？",
      "options": ["html", "txt", "exe", "css"],
      "answer": "A",
      "explanation": "HTML 文件的扩展名是 .html。"
    },
    {
      "question": "以下哪些属于浏览器？",
      "options": ["Edge", "Chrome", "Photoshop", "Firefox"],
      "answer": ["A", "B", "D"],
      "explanation": "Edge、Chrome 和 Firefox 都是浏览器。"
    }
  ]
}
```

### 字段说明

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `title` | 否 | 题库名称，显示在答题页和结果页。缺失或为空时使用文件名（去掉 `.json`）。必须是字符串。 |
| `reviewMode` | 否 | 答题模式：`"immediate"` 表示逐题查看答案，`"afterAll"` 表示全部答完后查看答案。省略时默认为 `"immediate"`。 |
| `questions` | 是 | 非空题目数组。 |
| `questions[].question` | 是 | 题干，非空字符串。支持换行。 |
| `questions[].options` | 是 | 2–26 个非空字符串组成的选项数组。 |
| `questions[].answer` | 是 | 单选时为一个字母（如 `"A"`）；多选时为字母数组（如 `["A", "C"]`）。大小写不敏感。 |
| `questions[].explanation` | 否 | 解析文字，答题结束后显示。必须是字符串。 |

未知字段会被忽略。

### 答题模式

#### `"immediate"`：逐题查看答案

- 每题选择答案后点击“提交答案”，立即显示对错、正确答案和解析，随后该题答案锁定。
- “上一题”可回看之前已经提交的题目；用“下一题”继续答题。
- 答完最后一题后点击“查看结果”。

#### `"afterAll"`：全部答完查看答案

- 作答过程中不显示正确答案和解析，可使用“上一题”和“下一题”来回检查或修改答案，选择会自动保留。
- “查看结果”按钮在所有题目都至少选择了一个答案后才可用。
- 全部题目完成后点击“查看结果”，统一判分并显示答案解析。

### 结果页

两种模式结束后都会分别显示：

- **错题与解析**：答错的题目、你的答案、正确答案和解析；
- **正确题目解析**：答对的题目、正确答案和解析。

如果该组没有题目，会显示“无错题。”或“无正确题目。”。题库未提供解析时显示“解析：题库未提供解析。”。

### 答案规则

- 选项按数组顺序自动标为 A、B、C……；`answer` 使用对应的字母。
- `answer` 是字符串时按**单选题**处理，界面显示单选框。
- `answer` 是数组时按**多选题**处理，界面显示复选框；即使数组只有一个字母，也按多选题处理。
- 多选答案不能为空，不能包含重复字母，也不能引用不存在的选项。
- 多选必须与正确答案集合完全一致才得分，没有部分分。
- 判分结果按题统计，最终正确率四舍五入为整数百分比。

## 校验与错误提示

加载时会校验整个文件。以下情况不会进入答题页，而是回到起始页显示具体错误：

- 文件不是合法 JSON；
- 根节点不是对象，或 `questions` 不是非空数组；
- `reviewMode` 不是 `"immediate"` 或 `"afterAll"`；
- 题目的题干、选项为空，或选项数量不在 2–26 之间；
- `answer` 格式错误、字母越界或重复；
- `title`、`explanation` 不是字符串。

若中文显示为乱码，请确认题库文件以 UTF-8 保存。Windows 记事本保存时可在编码选项中选择“UTF-8”。

## 界面与快捷键

- 单选可用方向键切换选项，多选可用空格勾选；Tab 键可聚焦选项和按钮。
- 逐题查看答案模式下，提交后选项锁定；全部答完模式下，可在“查看结果”前修改答案。
- 结果页提供“重新答题”和“选择题库”。
